---
### **🔍 Task Breakdown**
**Task 1: Caesar Cipher**

A Python tool that uses a shift-based substitution cipher to encrypt or decrypt text.

Input: Plaintext or ciphertext, and shift key

Output: Encrypted or decrypted text

Use case: Understanding classical encryption methods

---
**Task 2: Image Encryption via XOR**

Encrypts or decrypts an image by applying an XOR operation on each pixel.

Input: Image file and secret key

Output: Encrypted/Decrypted image file

Use case: Intro to image security techniques

---
**Task 3: Password Complexity Checker**

Analyzes password strength based on:

Length

Uppercase/Lowercase mix

Numbers

Special characters

Use case: Enforcing strong password policies

---

**Task 4: Simple Keylogger (Ethical Use Only)**

Logs keystrokes to a file for monitoring purposes.

Use case: Ethical security testing, monitoring personal devices

⚠ Warning: Illegal to use without permission. Educational purposes only.

### 🛠 How to Run

Clone the repository:

git clone https://github.com/itzaka-07/PRODIGY_CS.git
cd PRODIGY_CS


Navigate to a task folder and run:

python task_script.py


(Replace task_script.py with the actual filename inside the task folder.)

---

### 🧪 Example Use Cases

Task 1: Enter text: HELLO → shift key 3 → output KHOOR

Task 2: Encrypt image.png with key 12345 → output image_encrypted.png

Task 3: MyP@ssw0rd123 → Score: Strong

Task 4: Run, then type in a text editor — keystrokes saved to log.txt
